# WATCH.21 — دليل عربي سريع

`w21` أداة لتنظيم مراحل الاستطلاع الأمني والاختبارات المصرّح بها على Kali
Linux. النسخة الحالية **Alpha** وليست إصدار Production نهائياً.

## حالة النسخة الحالية

- اختبارات السكربت: **37 ناجح، 0 فاشل، 1 متجاوز**
- اختبارات مثبت الأدوات: **22 ناجح، 0 فاشل**
- اختبار تشغيل الأمر بعد التثبيت: ناجح
- وضع `dry-run`: تم التحقق أنه لا يرسل طلبات شبكة

تتضمن النسخة الحالية 26 مرحلة، حفظ الحالة، الاستكمال، التقارير، فحص الأدوات،
وإعدادات الحد من السرعة والموارد. محرك Scope المركزي على مستوى كل طلب، نظام
Workers المتعدد، والتحقق المستقل الكامل من النتائج ما زالت ضمن خطة التطوير.

## التنزيل

```bash
git clone https://github.com/watch-21/W21.git w21
cd w21
chmod +x w21 install.sh
./w21 --doctor
```

## تثبيت الأمر

```bash
./install.sh
export PATH="$HOME/.local/bin:$PATH"
w21 --version
```

المثبّت يثبت ملفات WATCH.21 فقط، ولا يبدأ أي فحص ولا يثبت أدوات الاستطلاع
تلقائياً. راجع خطة الأدوات أولاً:

```bash
w21 --print-install-plan
w21 --install-missing
```

## أول تجربة آمنة

ابدأ دائماً بوضع `dry-run` الذي لا يرسل طلبات شبكة:

```bash
w21 --target example.com --profile safe --dry-run
```

أمثلة إضافية:

```bash
w21 --help
w21 --doctor --json
w21 --targets targets.txt --dry-run
w21 --scope scope.txt --dry-run
w21 --resume --output results/example.com
```

## قواعد Scope الأساسية

| القاعدة | معناها |
|---|---|
| `example.com` | المضيف نفسه فقط |
| `*.example.com` | النطاقات الفرعية فقط، ولا يشمل النطاق الأساسي تلقائياً |
| `!admin.example.com` | استثناء، والاستثناء له الأولوية |

راجع ملف [scope.example.txt](../scope.example.txt) ونتيجة Scope الفعلية قبل أي
تشغيل شبكي. استخدم حدود سرعة قليلة في النسخة Alpha.

## النتائج

اختر مجلد نتائج واضحاً لكل هدف:

```bash
w21 --target example.com --profile safe --output results/example.com
```

يحتوي المجلد على الحالة، Scope، البيانات الخام والمنظمة، السجلات، الأدلة
والتقارير بحسب المراحل التي اكتملت.

تشغيل فحص فعلي مسموح فقط على نظام تملكه أو لديك تصريح صريح لاختباره. راجع
[المشاكل والحدود المعروفة](KNOWN_LIMITATIONS.md) قبل أي فحص شبكي.
