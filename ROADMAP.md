# WATCH.21 roadmap

## 0.1 — Public alpha foundation

- WATCH.21 branding and `w21` command
- Clean public repository layout
- User-local installer and Kali/Debian doctor workflow
- Offline tests, CI, scope examples, and honest limitations

## 0.2 — Python foundation

- Python package and typed CLI
- Central fail-closed Scope Engine
- SQLite migrations and durable project state
- Structured JSONL events and stable identifiers

## 0.3 — Coordinator and workers

- Atomic job leases, heartbeats, retries, and crash recovery
- Shared rate and resource budgets
- Pause, resume, cancel, retry, and multi-terminal workers

## 0.4 — Adapters and evidence

- Stable adapter contracts and parser fixtures
- Provenance-preserving normalization and deduplication
- Candidate/validated separation and redacted evidence bundles

## 0.5 — Reporting and release hardening

- Consistent JSON, JSONL, Markdown, and HTML reports
- Local integration lab and end-to-end acceptance tests
- Reproducible packaging and signed release artifacts

A milestone is complete only when implementation, tests, and documentation
agree. Placeholders are not counted as completed features.
